Portfolio Template — 內容管理工具

使用教學

👋 歡迎！這個工具讓你不碰程式碼就能修改網站內容

所有內容都存在一個 JSON 檔案裡，修改步驟超簡單：

  1. 編輯 — 點左邊選單，修改你要改的內容
  2. 匯出 — 點右上角 💾 匯出儲存，會下載 site-data.json
  3. 替換 — 把下載的檔案放到網站的 data/ 資料夾，覆蓋舊檔

📺 YouTube 影片怎麼填？

直接貼 YouTube 網址就好！系統會自動辨識。以下格式都支援：

  • https://www.youtube.com/watch?v=abc123 — 一般影片
  • https://youtu.be/abc123 — 短網址
  • https://youtube.com/shorts/abc123 — Shorts 短影音
  • abc123 — 直接填 ID 也可以

Shorts 會自動用直式排版顯示！

📸 Instagram 貼文怎麼填？

直接貼 IG 貼文網址就好！系統會自動嵌入顯示。

  • 打開 IG 貼文 → 點右上角 ⋯ → 複製連結
  • 貼到「創作動態」→「Instagram 貼文」欄位
  • 不需要截圖，不需要上傳圖片

🚀 如何上架到 GitHub Pages（免費架站）

  1. 註冊 GitHub 帳號（免費）
  2. 安裝 GitHub Desktop（圖形化工具，不用打指令）
  3. 打開 GitHub Desktop → File → Add Local Repository → 選擇這個網站資料夾
  4. 點 Publish repository（名字隨意，例如 myportfolio）
  5. 上傳完成後，到 GitHub 網站 → 你的 repo → Settings → Pages
  6. Source 選 main branch → Save
  7. 等 1-2 分鐘，你的網站就上線了！網址是 https://你的帳號.github.io/repo名稱/

🚀 如何更新網站內容（一鍵發布）

  1. 打開這個管理工具（admin.html），修改你要改的內容
  2. 點右上角 🚀 發布到 GitHub
  3. 首次使用會要求填入 GitHub 設定（之後會自動記住）
  4. 發布成功後，等 1-2 分鐘網站就更新了！

備用方式：也可以用 💾 匯出儲存 下載 JSON，手動上傳到 GitHub。

🔑 如何取得 GitHub Personal Access Token

  1. 登入 GitHub → 右上角頭像 → Settings
  2. 左側選單最下面 → Developer settings
  3. 選 Personal access tokens → Tokens (classic)
  4. 點 Generate new token (classic)
  5. Note 填「Portfolio Admin」，Expiration 選你想要的期限
  6. 權限勾選 repo（整個 repo 區塊打勾）
  7. 點 Generate token，複製產生的 ghp_ 開頭的 token

注意：Token 只會顯示一次，請妥善保存。如果忘了可以重新產生一個。

🌐 自訂網域（購買＆設定）

想要自己的網域名稱？例如 www.yourname.com

  1. 購買網域：到以下平台購買（通常一年 300-600 台幣）
    • Namecheap（推薦，介面簡單）
    • GoDaddy
    • Gandi
  2. DNS 設定：到你的網域管理後台，新增以下記錄：
    • A 記錄 → @ → 185.199.108.153
    • A 記錄 → @ → 185.199.109.153
    • A 記錄 → @ → 185.199.110.153
    • A 記錄 → @ → 185.199.111.153
    • CNAME 記錄 → www → 你的帳號.github.io
  3. 建立 CNAME 檔案：在網站根目錄建立一個叫 CNAME 的檔案（無副檔名），裡面只寫你的網域，例如 www.yourname.com
  4. GitHub 設定：repo → Settings → Pages → Custom domain → 填入你的網域 → 勾選 Enforce HTTPS
  5. 等 30 分鐘～幾小時，DNS 生效後就能用了！

更換網域：只需修改 CNAME 檔案的內容 + 修改 DNS 設定即可。

💡 小提醒

  • 每次改完記得按 💾 匯出儲存，不然修改會消失
  • 改壞了可以按 📂 匯入 JSON 重新載入原本的檔案
  • 圖片要自己放到 assets/images/ 資料夾
  • 可以用 📁 選擇檔案 按鈕來瀏覽 assets 裡的檔案
